“Our project name is Robot Township. It is a puzzle-based township simulation game developed using Python and Pygame. In this game, the player solves different puzzles and earns coins, XP and robot parts. Coins are used to construct buildings, manage farming and upgrade the robot. As the township develops, population and happiness increase. The game also contains missions, achievements, difficulty progression and automatic game systems. Player progress is stored using JSON.”
